# Event Management System

A full-stack Event Management System developed as part of the **Web Application Development** summer coursework.

## Features

- Event management (Create, Read, Update, Delete)
- Attendee management (Create, Read, Update, Delete)
- Event registration
- Admin authentication
- Search events
- Form validation

## Tech Stack

### Frontend

- React
- React Router
- Axios

### Backend

- Node.js
- Express.js

### Database

- SQLite
- Sequelize ORM

## Project Structure

```
event-management-system/
├── client/     # React frontend
├── server/     # Express backend
└── README.md
```

## Getting Started

### Clone the repository

```bash
git clone <repository-url>
cd event-management-system
```

### Install dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd ../server
npm install
```

### Run the application

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
cd ../client
npm run dev
```
